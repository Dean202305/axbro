# UI assets

ChatGPTMark.png and ChatGPTMark@2x.png are original ChatGPT template marks supplied with the local OpenAI desktop application. They retain their original aspect ratio and are used as a small Codex-related action-menu icon, not as axbro branding. The marks belong to OpenAI. Official brand guidelines: https://openai.com/brand/ .

WeatherReference.png is the weather icon sheet supplied by the user for this project; its sprites are extracted by the existing native weather renderer without geometric distortion.

AxbroLogo.png is the user-selected A concept, refined as axbro's own app mark with imagegen: an ivory lowercase a, a mint quota arc and endpoint dot, on an opaque charcoal rounded tile with transparent outer margins. It contains no OpenAI mark. Master: 1024 × 1024 RGBA. Run Source/make-app-icon.command to regenerate Source/AppIcon.icns with the standard 16–1024 pixel macOS representations. The static brand icon does not replace the live menu-bar quota indicator or the separate ChatGPT action icon.
